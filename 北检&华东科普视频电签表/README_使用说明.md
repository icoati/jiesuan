# 北检&华东科普视频电签表 一键生成工具使用指南

本工具专为科普视频劳务结算业务定制，支持自动将【任务编号表】、【科普视频明细表】、【专家用户信息表】三方数据进行智能勾稽，并生成符合第三方导入系统严格规范的纯净版《科普电签表.xlsx》。

---

## 一、源文件准备

请将以下 3 个文件放入本文件夹中（或在 Web 平台统一上传）：
1. **任务编号表**（文件名含「任务编号」或「任务」，如《科普视频任务编号.xlsx》）；
2. **科普视频明细表**（文件名含「明细」或「视频」，如《科普视频明细表.xlsx》）；
3. **专家用户信息表**（文件名含「用户信息」或「用户」，如《科普视频用户信息表.xlsx》）。

---

## 二、使用方式

### 方式 1：Web 统一门户（推荐）
在项目主目录下运行 `app.py` 或双击 `一键启动服务.bat`，切换到「北检&华东科普视频电签表」模块，拖入 3 个文件后一键生成并在线预览。

### 方式 2：本地离线双击运行
- **Windows 用户**：直接双击 `run_windows.bat`；
- **Mac 用户**：直接双击 `run_mac.command`。

### 方式 3：终端命令行自定义路径
```bash
python generate_sign_table.py --task 你的任务表.xlsx --detail 你的明细表.xlsx --user 你的用户表.xlsx --out 输出路径.xlsx
```

---

## 三、生成标准规范

1. **表头 18 列规范**：
   `姓名*`, `开始年*`, `开始月*`, `终止年*`, `终止月*`, `项目名称*`, `金额*`, `姓名1*`, `省份*`, `市*`, `身份证*`, `手机号*`, `开户行*`, `银行卡号*`, `工作单位*`, `医务职称*`, `签署日期`, `签署日期1`
2. **纯净未渲染规范**：
   - 彻底剔除背景颜色（fill=None）、边框（border=None）与特殊字体，保持原始 Excel 纯净数据结构；
   - `开始年*`、`开始月*`、`终止年*`、`终止月*` 4 列数据单元格完全置空 (None)；
   - `金额*` 为纯整数数值（无千分位逗号）；
   - `身份证*`、`手机号*`、`银行卡号*` 为纯文本字符串（@），杜绝科学计数法截断。
