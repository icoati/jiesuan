==================================================
  心血管内科报表统计工具 - 使用说明
==================================================

【这个文件夹里有什么】
  ├─ 一键统计.command   ← Mac 双击运行（推荐）
  ├─ 统计报表.js         ← 核心脚本（Mac/Windows 都能用）
  ├─ 使用说明.txt        ← 你正在看的这个
  └─ node_modules        ← 依赖文件（首次运行后自动生成）


==================================================
  首次使用（只需做一次）
==================================================

【安装 Node.js】
  方式一（推荐）：打开浏览器访问 https://nodejs.org
                  下载「LTS 版本」，双击安装，一路下一步
  方式二：打开「终端」App，粘贴并回车：
                  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
                  brew install node


==================================================
  每次生成报表（超简单！）
==================================================

  1. 从系统导出两个 Excel 表格：
       - 答卷记录表（含「答卷记录」工作表的那个）
       - 项目人员列表（含「项目人员」工作表的那个）
     【文件叫什么名字都可以，不用改名！】

  2. 把这两个 xlsx 文件拖到本文件夹里

  3. 双击「一键统计.command」

  4. 首次会自动安装依赖，稍等几秒
     之后每次直接生成，几秒钟搞定

  5. 文件夹里会多出一个「统计总表.xlsx」
     这就是给客户的最终报表！


==================================================
  生成的报表包含 3 个工作表
==================================================

  📊 统计汇总  - 按省份汇总任务数量 + 总计
  👥 人员维度  - 所有心血管内科项目人员详情
  📋 案例维度  - 全部答卷记录（含审核通过/不通过）


==================================================
  Windows 电脑怎么用？
==================================================

  方式一（命令行，同 Mac）：
     打开 CMD 或 PowerShell，cd 到本文件夹，执行：
        node 统计报表.js

  方式二（WPS VBA）：
     使用桌面上的「生成报表_WPS - 副本.bas」
     方法见之前的对话说明


==================================================
  常见问题
==================================================

  Q: 双击 .command 提示「无法打开」？
  A: 右键点击 → 选择「打开」→ 再次点「打开」
     （Mac 对未签名脚本的默认安全限制，只需第一次这么做）

  Q: 提示找不到文件？
  A: 确认两个 xlsx 文件和 .command 在同一文件夹
     确认文件能正常打开（没有被占用或损坏）

  Q: 文件名变了有影响吗？
  A: 没影响！脚本根据「工作表名称」识别，不看文件名

  Q: 想换一批数据重新生成？
  A: 删除旧的 xlsx，放进新的，再双击 .command 即可
