==================================================
  心血管内科报表统计工具 - 使用说明 (Python 原生版)
==================================================

【这个文件夹里有什么】
  ├─ 统计报表.py         ← 核心 Python 脚本（跨平台 Windows/Mac/Linux）
  ├─ run_windows.bat     ← Windows 双击运行
  ├─ 一键统计.command   ← Mac 双击运行
  └─ 使用说明.txt        ← 你正在看的这个


==================================================
  环境准备（只需确保已安装 Python 3）
==================================================

【依赖库安装】
  打开终端（Terminal）或命令行（CMD / PowerShell），运行：
  pip install openpyxl


==================================================
  每次生成报表（超简单！）
==================================================

  1. 从系统导出两个 Excel 表格：
       - 答卷记录表（含「答卷记录」工作表的那个）
       - 项目人员列表（含「项目人员」工作表的那个）
     【文件叫什么名字都可以，不用改名！】

  2. 把这两个 xlsx 文件拖到本文件夹里

  3. 运行方式：
     - Windows 用户：双击「run_windows.bat」或者运行 `python 统计报表.py`
     - Mac 用户：双击「一键统计.command」或者运行 `python3 统计报表.py`
     - Web 控制台：直接在 Streamlit 结算平台上传运行

  4. 文件夹里会多出一个「统计总表.xlsx」
     这就是给客户的最终报表！


==================================================
  生成的报表包含 3 个工作表
==================================================

  📊 统计汇总  - 按省份汇总任务数量 + 总计
  👥 人员维度  - 所有心血管内科项目人员详情
  📋 案例维度  - 全部答卷记录（含审核通过/不通过）


==================================================
  常见问题
==================================================

  Q: 提示找不到文件？
  A: 确认两个 xlsx 文件在同一文件夹中。
     确认文件能正常打开（没有被 Excel 独占锁定或损坏）。

  Q: 文件名变了有影响吗？
  A: 没影响！脚本根据「工作表名称」识别，不看文件名。

  Q: 想换一批数据重新生成？
  A: 删除旧的 xlsx，放进新的，再次运行即可。
