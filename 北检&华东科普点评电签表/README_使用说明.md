# 北检&华东科普点评电签表 使用指南与规范说明

本工具专为**专家科普点评劳务结算业务**定制，支持自动将【任务编号表】、【点评参与明细表】、【结算数据/专家档案表】三方数据进行智能嗅探与勾稽，生成符合第三方导入系统严格规范的纯净版《科普点评电签表.xlsx》。

---

## 一、 源文件准备

请将以下 3 个文件放入本文件夹中（或通过 Web 平台统一上传）：
1. **任务编号表**（文件名含「任务」或「编号」，如《点评-任务明细编号.xlsx》）；
2. **点评参与明细表**（文件名含「点评」或「参与」，如《点评-参与数据-2026-09-17.xlsx》）；
3. **结算数据/专家档案表**（文件名含「结算」或「用户」或「专家」，如《结算数据-2026-09-16.xlsx》）。

---

## 二、 使用方式

### 方式 1：Web 统一门户（推荐）
在主平台 Web 界面左侧切换至「**北检&华东科普点评电签表**」模块，拖拽上传上述 3 个表格后，即可一键生成、在线预览与一键下载。

### 方式 2：本地离线双击运行
- **Windows 用户**：直接双击 `run_windows.bat`；
- **Mac 用户**：直接双击 `run_mac.command`。

### 方式 3：终端命令行
```bash
python generate_dianping_sign_table.py --dir "你的源文件目录" --out "科普点评电签表.xlsx"
```

---

## 三、 生成标准与第三方导入规范

1. **表头 18 列规范**：
   `姓名*`, `开始年*`, `开始月*`, `终止年*`, `终止月*`, `项目名称*`, `金额*`, `姓名1*`, `省份*`, `市*`, `身份证*`, `手机号*`, `开户行*`, `银行卡号*`, `工作单位*`, `医务职称*`, `签署日期`, `签署日期1`
2. **四列严格置空**：
   `开始年*`、`开始月*`、`终止年*`、`终止月*` 4 列数据单元格完全置空（`None`），签署日期亦置空；
3. **纯净未渲染**：
   彻底剔除背景颜色（fill=None）、边框（border=None）与特殊字体，保持原始 Excel 纯净数据结构；
4. **格式防截断**：
   `身份证*`、`手机号*`、`银行卡号*` 格式严格设置为文本（@），剔除 `.0` 脏后缀与科学计数法截断；
   `金额*` 为纯整数字值。
