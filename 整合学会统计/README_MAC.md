# Mac 端一键结算工具使用指南

本套脚本专为 **macOS** 优化编写，完整封装了《语料库结算明细》自动聚合反算到《劳务明细总表》与《任务明细表》的全部业务逻辑，包含个税反算、增值税附加及合计公式。

---

## 一、文件清单

| 文件 | 说明 |
| :--- | :--- |
| **`run_on_mac.command`** | **Mac 双击启动器**（推荐：双击即可全自动检测依赖并运行） |
| **`settlement_mac.py`** | **核心 Python 结算程序**（同时支持 Mac 视窗图形界面与命令行运行） |

---

## 二、在 Mac 上的使用方法

### 方式 1：双击运行（最简方式）
1. 将本次结算需要的 Excel 文件（如《（已确认）语料库结算明细.xlsx》和《任务明细.xlsx》）放入该文件夹中；
2. **首次使用**：打开 Mac 终端（Terminal），执行一次赋予可执行权限命令：
   ```bash
   chmod +x run_on_mac.command
   ```
3. 在访达（Finder）中**直接双击 `run_on_mac.command`**：
   - 脚本会自动检测并补齐 `openpyxl` 依赖；
   - 弹出原生图形操作窗口（也可以直接在当前目录下全自动扫描处理）；
   - 一键生成两份标准 Excel 文件，并在窗口内显示“勾稽校验 100% 吻合”报告。

---

### 方式 2：终端命令行运行
打开 Mac 终端，进入该文件夹后运行：
```bash
# 启动图形界面窗口模式
python3 settlement_mac.py

# 或者纯命令行无交互全自动生成
python3 settlement_mac.py --cli
```

---

## 三、生成的两份标准表格

1. **`劳务明细总表_YYYYMMDD.xlsx`**：
   - 包含 `明细1`、`明细2`、`明细3` 三个 Sheet，表头标准字段带 `##`；
   - 包含全部医生实发求和、**个税反算公式**、**1.51% 增值税及附加成本公式**、**应发金额求和公式**与**底部 SUM 合计公式**；
   - 银行卡号和开户行严格对齐语料库最新真实网点。

2. **`任务明细表_YYYYMMDD.xlsx`**：
   - 10 列标准结构，按医生聚合顺序完整展开每笔任务详情、单价、审核状态及作品音频链接；
   - 任务总金额与劳务实发总金额严格勾稽一致。
