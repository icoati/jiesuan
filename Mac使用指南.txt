# 🍎 医疗数据统计与劳务结算平台 - Mac 使用指南

欢迎使用医疗数据统计与劳务结算平台！本包已针对 macOS 系统进行原生适配，支持 Intel 及 Apple Silicon (M1/M2/M3/M4) 系列芯片。

---

## 🚀 方式一：最简双击启动（推荐）

1. **解压本压缩包**至您的任意文件夹（例如：`下载` 或 `文稿`）。
2. **直接双击运行**：
   - 👉 **`启动.command`** 或 **`一键启动服务_Mac.command`**
3. 终端会自动检测 Python 环境并启动服务，自动调起浏览器打开 `http://localhost:8501`。
4. 退出服务时，直接关闭终端窗口或在终端按 `Ctrl + C` 即可。

---

## 🖥️ 方式二：生成桌面原生图标 App

如果您希望像普通 Mac 软件一样直接从桌面或 Dock 栏点开：
1. 双击运行 **`创建Mac桌面App.command`**。
2. 稍等 2 秒，您的桌面会自动生成 **`医疗数据统计平台.app`**。
3. 今后直接双击桌面图标即可秒开平台！

## ❓ 常见问题排查（FAQ）

### Q1：双击提示“由于没有适当的访问权限，不能打开文件”？
**原因**：从微信/网络下载的文件，macOS 系统可能会默认去掉执行权限位。
**解决方法**：
- **方案 A（一键修复）**：双击运行本目录下的 **`首次使用_权限修复.command`**。
- **方案 B（终端单行命令）**：打开终端，进入当前文件夹，执行：
  ```bash
  chmod +x *.command
  ```

### Q2：双击提示“打不开，因为无法验证开发者 / 无法检查恶意软件”？
**解决方法**：
- 在脚本上点击鼠标 **右键（或双指轻按触控板）** -> 选择 **「打开」** -> 在弹出提示中点击 **「打开」** 即可。只需右键点一次，后续即可直接双击。

### Q3：提示“未检测到 Python 3 运行环境”？
**解决方法**：
- 前往 Python 官方下载安装：[https://www.python.org/downloads/macos/](https://www.python.org/downloads/macos/)
- 或在终端运行安装命令：`brew install python`
