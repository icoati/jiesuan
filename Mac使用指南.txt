# 🍎 医疗数据统计与劳务结算平台 - Mac 使用指南

欢迎使用医疗数据统计与劳务结算平台！本应用已深度适配 macOS 系统（Intel / Apple Silicon M1-M4），并内置 GitHub 自动热更新机制。

---

## 🌟 方式一：独立桌面客户端（最推荐，支持 GitHub 自动同步）

1. **直接双击** 目录内的 **`医疗数据统计平台.app`**（带有专属医疗蓝/绿图标），或双击 **`创建Mac桌面App.command`** 将其快捷生成到桌面。
2. **自动推送更新**：
   - 每次点击打开应用，它均会**静默连接 GitHub 检查并拉取最新推送**（包括新模块、算法优化、UI 升级等）。
   - 自动清理可能驻留的旧服务进程（端口 8501），杜绝新版本不生效的问题。
   - 自动拉起 Chrome / Edge 无边框独立 App 窗口，体验与原生 Mac 软件完全一致！
   - 断网或离线时会自动快速跳过更新，直接秒开本地版本。

---

## 🚀 方式二：终端双击启动

- 直接双击 **`启动.command`** 或 **`一键启动服务_Mac.command`**。
- 启动前同样会自动检测 GitHub 更新并释放端口。
- 退出时直接关闭终端窗口或按 `Ctrl + C` 即可。

---

## 🔄 方式三：手动强制更新

- 若想立即强制从 GitHub 拉取最新主分支代码，双击 **`一键更新_Mac.command`** 即可。

---

## ❓ 常见问题排查（FAQ）

### Q1：提示“无法验证开发者”或“由于没有适当的访问权限，不能打开文件”？
**解决方法**：
- 双击运行本目录下的 **`首次使用_权限修复.command`**，一键清除系统的隔离标记 (Quarantine) 并修复执行权限。
- 或在应用图标上点击鼠标 **右键（或双指点按）** -> 选择 **「打开」** -> 点击弹出框的 **「打开」** 即可。

### Q2：更新后页面没出现新模块（如“调研案例电签表”）？
**原因**：旧版 Streamlit 服务驻留在后台占用 8501 端口。
**解决方法**：
- 新版 `医疗数据统计平台.app` 和 `一键启动服务_Mac.command` 已内置自动进程清理，直接双击重新打开即可自动解决！
- 也可以在终端输入命令直接清理：`lsof -ti:8501 | xargs kill -9`。

### Q3：提示“未检测到 Python 3 运行环境”？
**解决方法**：
- 前往官网下载安装：https://www.python.org/downloads/macos/
- 或在终端输入：`brew install python`
