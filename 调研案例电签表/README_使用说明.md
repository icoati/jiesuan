# 调研案例电签表 一键智能生成工具

用于医药调研、案例征集等多问卷/多案例收集类业务的电签结算表格一键生成。

---

## 📁 使用方式

### 方式一：在平台 Web 门户中直接使用（推荐）
在主平台（运行根目录下的 `启动.command` 或 `一键启动服务.bat`）中，左侧导航栏选择 **【调研案例电签表】**，直接拖拽上传表格即可。

---

### 方式二：本目录下独立一键运行
1. 将本期的 **2~3 个源表格** 放入本文件夹中：
   - **答卷明细表**（必须，包含答卷记录、明文身份证/手机号、获得积分、任务名称等）；
   - **项目人员列表**（必须，包含医生银行卡号、银行名称、支行等专家档案）；
   - **进度确认表**（可选/推荐，包含审核通过、确认结算的任务明细编码清单；若未提供将自动按明细表中的“审核通过”结算）。
2. 直接双击运行：
   - **Windows 用户**：双击运行 `一键运行_Win.bat`
   - **Mac 用户**：双击运行 `一键运行_Mac.command`
3. 运行完成后，将自动生成：
   - `调研案例电签表-YYYY-MM-DD.xlsx`（标准 20 列电签表）
   - `调研案例电签表-YYYY-MM-DD.xls`（标准 BIFF8 银行/电签通用导入表）
   - `【警告】待核查异常名单.txt`（若有未绑卡或开户行异常专家）

---
