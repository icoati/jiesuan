# 医疗健康语料库 - 每月结算一键生成工具（Mac 使用指南）

本项目专为 **Mac（macOS）** 环境设计，实现了每月语料结算的“零手工复制、一键秒级生成”。

---

## 🚀 极简使用流程（只需三步）

### 第一步：放表格
每个月从后台或系统下载好当月的表格后，**直接拷贝到本文件夹**中：
1. **三方项目支付清单**（包含要结算的语料编号、单价）
2. **语料列表(明文)**（包含所有语料编号、题目内容、医生姓名、身份证等）
3. **用户列表(明文)**（包含医生身份证、银行卡号、开户行等）

> 💡 **无需重命名**：工具会自动根据内容与表头智能识别哪张是支付清单、哪张是语料明文、哪张是用户列表！

---

### 第二步：双击运行
在 Mac 的 **访达（Finder）** 中，直接**双击运行**：
👉 **`一键运行.command`**

终端窗口会自动弹出，并显示：
1. 自动检查并安装所需库（仅首次）
2. 自动匹配 3 张表格并显示结算周期（如【2026年08月】）
3. 自动抓取表头、校验卡号完整性并计算金额
4. 自动弹出生成结果所在的文件夹！

---

### 第三步：获取结果
执行完成后，文件夹内会自动更新以下文件：
- **`最终.xlsx`**：现代格式标准发放表（带排版格式，推荐日常查看）
- **`最终.xls`**：经典 BIFF8 格式标准发放表（严格 17 列，可直接导入银行或灵活用工系统）
- **`语料列表(明文)-X月结算筛选.xlsx`**：
  - **Sheet 1**：当月结算语料的完整问答与明文字段（带银行卡号，方便审计）
  - **Sheet 2**：医生个人维度的结算总表与合计对账

## 🛠️ Mac 首次使用常见小技巧

### 1. 首次双击提示“没有权限”或闪退？
在 Mac 终端中给该脚本添加一次执行权限即可：
1. 打开 Mac 上的【终端】（Terminal）应用程序。
2. 输入 `chmod +x `（注意后面有一个空格）。
3. 把 `一键运行.command` 文件直接拖进终端窗口，然后按 **回车（Enter）**。
4. 之后就可以永久直接双击运行了！

### 2. 提示“无法打开，因为来自未知的开发者”？
这是 macOS 的安全机制：
- **方法一**：按住键盘上的 **`Control` 键**，然后用鼠标点击 `一键运行.command`，在弹出菜单中选择 **【打开】**，之后点击【仍要打开】即可。
- **方法二**：打开 Mac 【系统设置】 -> 【隐私与安全性】，滑到下方点击【仍要打开】。

### 3. 如果想在终端手动运行？
打开终端，进入该文件夹，运行：
```bash
python3 settlement_tool.py
```

## 💡 核心设计与智能优化亮点

1. **表头别名容错匹配**：
   - 即使后台导出列顺序变动、或者列名轻微变化（如“身份证号码”变“身份证号”、“所在医院”变“医院”、“开户银行”变“开户行”），脚本内置丰富的同义词库，自动匹配抓取，无需人工调整列。
2. **银行卡号防失真保护**：
   - 写入时强制底层指定文本标识符，彻底防止 Mac Excel / Numbers 将 19 位卡号自动转换为科学计数法导致后 4 位变为 0。
3. **医院与省市智能引擎**：
   - 内置医疗机构所属省市解析规则，根据医院名称自动提取省份与地级市（如温州、杭州、金华、台州、丽水等）。
4. **异常预警保护**：
   - 若某位医生有结算记录但在用户表中未录入银行卡号，脚本会标红提示，并在当前目录生成《【警告】待核查异常名单.txt》，防止错发漏发。
