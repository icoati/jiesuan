# 雷允上语料库劳务费用明细表 一键导出工具使用指南 (Mac / Windows 通用)

本工具为雷允上语料库项目定制开发，可实现**一键自动关联进度表、语料明文表与用户明文表**，并按标准财务报表模板导出规范的费用明细 Excel 文件。

---

## 一、在 Mac 笔记本上使用方法

### 方式 1：双击一键运行（推荐）
1. 将本文件夹解压或拷贝至您的 Mac 电脑；
2. 将本期最新的 3 个源文件（进度表、语料明文表、用户明文表）放入该文件夹内；
3. **双击运行 `run_mac.command`**；
   - *提示：如果首次双击提示权限问题，只需打开 Mac「终端」(Terminal)，输入以下命令后回车即可：*
     ```bash
     chmod +x run_mac.command run_mac.sh
     ```
4. 脚本会自动检查环境依赖、匹配文件并导出最新的 `YYYYMMDD-劳务费用明细表.xlsx`。

### 方式 2：Mac 终端命令运行
打开 Mac 终端，进入当前文件夹目录，直接执行：
```bash
python3 generate_settlement.py
```

## 二、智能化特性说明

### 1. 文件名自动识别
脚本会在当前文件夹下自动扫描并锁定数据源，您无需手动重命名：
- **进度表**：文件名含有 `进度`（如 `雷允上语料库项目进度表20260903.xlsx`）；
- **语料明文表**：文件名含有 `语料`（如 `语料列表(明文)-2026-09-10 (2).xlsx`）；
- **用户明文表**：文件名含有 `用户`（如 `用户列表(明文)-2026-09-10 (1).xlsx`）。

### 2. 字段列名智能模糊匹配
后续从不同系统导出的表格即使**列名不同、列顺序调整**，脚本均能通过同义词库模糊自适应：
- **语料编号**：支持识别 `语料词条编号`、`语料编号`、`词条编号`、`语料id`、`编号`、`corpus_id`
- **医生姓名**：支持识别 `医生姓名`、`姓名`、`医生`、`专家姓名`、`专家`
- **手机号**：支持识别 `手机号`、`手机号码`、`电话`、`联系电话`
- **身份证号**：支持识别 `身份证号码`、`身份证号`、`证件号码`、`证件号`
- **结算单价**：支持识别 `结算单价`、`标签`、`单价`、`金额`、`费用`
- **开户行与支行**：支持识别 `开户银行`、`支行名称`、`开户支行`、`银行`，并自动清洗合并
- **银行卡号**：支持识别 `银行卡号`、`银行账号`、`卡号`、`账号`

### 3. 高级命令行参数（支持自定义路径）
如需指定特定文件夹或文件路径，可在终端传参运行：
```bash
python3 generate_settlement.py --prog 你的进度表.xlsx --corpus 你的语料明文.xlsx --user 你的用户明文.xlsx --output 输出文件名.xlsx
```

## 三、生成表单结构与公式

导出的 Excel 表格严格包含以下 4 个规范工作表：
1. **`汇总-劳务费用明细`**：合并所有项目（云南在前、长春在后），自动编号 1 至 N，含项目名称列；
2. **`雷允上云南-明细`**：云南项目医生结算清单，按税后金额从高到低排列；
3. **`雷允上长春-明细`**：长春项目医生结算清单，按税后金额从高到低排列；
4. **`语料结算明细对账表`**：逐条列出全部词条明细（包含未脱敏手机号、身份证号、题目内容、审核状态等）。

**内置公式**：
- **代扣个税**：严格按照劳务报酬税后反算税前公式植入（800元以下免税、800-3360、3360-21000等阶梯税率）；
- **收入额**：`税后金额 + 代扣个税` 自动联动；
- **合计行**：底部自动包含 Excel 动态求和公式 `=SUM(...)`。
