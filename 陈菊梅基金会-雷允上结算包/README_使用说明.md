# 雷允上语料库劳务费用明细表 一键导出工具使用指南 (Mac / Windows 通用)

本工具为雷允上语料库项目定制开发，基于**全自适应防乱序生产级引擎**，可实现**一键自动关联医生底表与语料交付表**，动态提取单价档位，并按标准财务报表模板导出规范的费用明细 Excel 文件。

---

## 一、使用方法 (Mac / Windows 通用)

### 方式 1：双击一键运行（推荐）
1. 将本文件夹解压或拷贝至您的电脑；
2. 将本期最新的源文件（医生底表/用户列表、语料交付表/进度表）放入该文件夹内；
3. **Windows 用户**：双击运行 `run_windows.bat`；
4. **Mac 用户**：双击运行 `run_mac.command`；
   - *提示：如果首次双击提示权限问题，只需打开 Mac「终端」(Terminal)，输入以下命令后回车即可：*
     ```bash
     chmod +x run_mac.command run_mac.sh
     ```
5. 脚本会自动检查环境依赖、智能匹配文件并导出最新的 `YYYYMMDD-劳务费用明细表.xlsx`。

### 方式 2：终端命令运行
打开终端，进入当前文件夹目录，直接执行：
```bash
python generate_settlement.py
```

## 二、智能化特性说明

### 1. 文件名与表数量智能自适应
- **极简 2 表驱动**：仅需【医生底表】（文件名含「用户」或「医生」）与【语料交付表】（文件名含「语料」或「进度」）；
- **传统 3 表兼容**：若同时提供进度表与语料表，系统将智能优先选取完整语料交付数据进行动态核销；
- **免手动重命名**：无论从平台导出为何种名称，均能自动嗅探。

### 2. 全数据驱动单价提取
- 动态读取源数据【结算单价】列中的所有去重单价档位（如 150, 100 等）；
- 自动动态创建对应的【语料单价X】列，列下直接显示医生完成的数量（条数），无交付自动填 0；
- 税后金额公式根据单价数值与条数列动态拼接（如 `=D4*150 + E4*100`），后序字段与合计行全自适应顺移。

### 3. 字段列名智能模糊匹配
彻底摆脱列名与顺序限制，自动通过同义词候选池智能匹配：
- **医生姓名**：支持识别 `医生姓名`、`姓名`、`医生`、`专家姓名`、`专家`
- **手机号**：支持识别 `手机号`、`手机号码`、`电话`、`联系电话`，防浮点数 `.0` 失真
- **身份证号**：支持识别 `身份证号码`、`身份证号`、`证件号码`、`证件号`，防科学计数法截断
- **结算单价**：支持识别 `结算单价`、`语料单价`、`单价`、`单价(元)`、`金额`、`费用`
- **开户行智能清洗**：自动纠正医生误填本人姓名至支行，消除重复银行名拼接，补齐漏字
- **银行卡号**：支持识别 `银行卡号`、`银行账号`、`卡号`、`账号`

### 4. 高级命令行参数（支持自定义路径）
如需指定特定文件夹或文件路径，可在终端传参运行：
```bash
python generate_settlement.py --doc 你的用户列表.xlsx --corpus 你的语料交付表.xlsx --out 输出文件名.xlsx
```

## 三、生成表单结构与公式

导出的 Excel 表格规范包含以下工作表：
1. **`项目结算表`**：汇总各单价档位、语料疾病领域、收集数量与参考结算费用，底部含动态求和公式；
2. **`雷允上{项目名称}-明细`**：医生结算清单，按税后金额从高到低排列，包含动态单价列（直接显示条数）。

**内置公式**：
- **税后金额**：根据动态单价列自动计算 `=D4*150 + E4*100`；
- **代扣个税**：严格按照劳务报酬税后反算税前公式植入（800元以下免税、800-3360、3360-21000等阶梯税率）；
- **收入额**：`税后金额 + 代扣个税` 自动联动；
- **合计行**：底部自动包含 Excel 动态求和公式 `=SUM(...)`。
